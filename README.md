# SVT Toranalyse v7 – einfache manuelle Version

## Enthalten
- Erste 15 Spiele mit Datum, Gegner, Heim/Auswärts und Ergebnis vorinstalliert
- Manuelle Minute und Mehrfachauswahl der Torarten für eigene Tore und Gegentore
- Zusammenfassung der häufigsten Torarten getrennt nach eigenen Toren und Gegentoren
- Torzeitanalyse in sechs 15-Minuten-Phasen
- Neue Spiele manuell hinzufügen
- Backup/Import

## Update
1. In der bisherigen App unbedingt Backup exportieren.
2. Dateien bei GitHub durch diese Version ersetzen.
3. Diese Version nutzt einen neuen, bewusst vereinfachten Datenspeicher. Alte v6-Bewertungen werden nicht automatisch übernommen.
4. Falls gewünscht, kann das alte Backup später separat konvertiert werden.

Cloudflare, BFV-Sync und FUSSBALL.DE-Widget werden nicht mehr benötigt.
